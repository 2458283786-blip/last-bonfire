# 地下城时间限制 & 夜袭强度动态公式 设计（2026-08-11）

> 状态：已实现（2026-08-11），P11/P12/P13 demo 落地并全绿（69 个测试）；节点图随机/商店解锁等后续迭代。

## 1. 地下城时间限制（P11）

### 1.1 机制

- 玩家进入地下通道后，**城镇时间照常流逝**（DayManager 为全局单例，地下城不暂停时间）。
- 进入时记录"距天黑剩余时间"：白天 = 白天剩余 + 黄昏整段；黄昏 = 黄昏剩余；夜晚 = 0。
- 地下城 HUD 显示"距天黑 xx 秒"；玩家自行权衡撤离时机。
- 若倒计时耗尽（探索太久）：视为城镇提前进入夜晚，直接推进到 NIGHT 阶段；返回城镇时触发当晚波次，且带"玩家不在场"加成（`away_bonus_multiplier`，默认 1.5，代表怪物多啃了一会）。
- 玩家提前撤离：城镇按正常时间继续，不额外惩罚。

### 1.2 防重复刷怪

- `DayManager.wave_triggered_tonight`：每晚只刷一波；进入 DAY 自动重置；随存档保存。
- 城镇 `NightWaveSpawner._ready` 检测：若加载时已是夜晚且当晚未刷 → 补刷（覆盖"晚归"与"读档在夜晚"两种情况）。

### 1.3 死亡与撤离

- 地下城出口（交互 E）→ 返回城镇，撤离不惩罚。
- 地下城死亡 → 回城镇（无彻底失败），掉落细节留待平衡阶段。

## 2. 夜袭强度动态公式（P12）

```text
波次数量 = clamp(round((天数基线 + 居民加成 + 建筑加成 + 囤积加成) × 晚归倍率 × 随机浮动), 0, 上限)
```

- 天数基线：`base_wave_size + (day-1) × wave_growth`（沿用，上限 10）。
- 居民加成：每 `villagers_per_point`(2) 人 +1。
- 建筑加成：每 `buildings_per_point`(3) 座未摧毁建筑 +1。
- 囤积加成：库存总量超过 `hoard_threshold`(60) 后，每 `hoard_per_point`(30) +1（逼玩家消耗资源，与商店/升级呼应）。
- 随机浮动：±`random_variance`(20%)，防精算。
- 晚归倍率：探索超时强制入夜时 ×1.5。
- 所有系数均为 `NightWaveSpawner` 导出配置，**待实测人口/建筑数据后调参**，不锁死。

## 3. 地下城第一版 demo（P13）

- 结构：固定线性路线——入口 → 战斗房 ×2 → 宝箱房 ×1 → Boss 房 ×1。
- 房间按 x 区间划分，墙体留门洞；房间类型用地面色带 + 标签标注。
- 战斗房：夜狼按配置生成（房间 1 ×2、房间 2 ×3）；Boss 房：1 只 Boss 夜狼（新 `enemy_boss_wolf.tres`，血量/伤害更高）。
- 宝箱房：地面掉落金币/怪物材料，玩家走过自动拾取入库——"探索 → 材料反哺城防"的第一条闭环。
- 出口：入口旁交互点，E 撤离。
- 扩展位：后续把房间替换为预制件库拼装（讨论稿 12.5），敌人/宝箱/房间类型全部数据驱动。
