# 《最后的篝火》游戏设计文档（Demo）

> 版本：v0.1（2026-08-05，框架搭建阶段）
> 状态：已与需求方讨论确认，作为后续开发依据；随开发迭代更新。

## 1. 项目定位

- **类型**：2D 横版 · 建造经营 + 探索战斗 + 生存防御
- **参考**：《王国两位君主》（城镇经营与夜晚防御氛围）、《小骨英雄杀手》（玩家动作战斗）
- **核心概念**：玩家作为人类文明的开拓者，在未知世界建立据点。通过探索战斗获取金币与材料，在城镇发展居民与建筑，抵御夜晚怪物，逐渐扩大生存空间。
- **Demo 目标**：验证核心体验——探索世界 → 战斗获取 → 建立据点 → 发展居民 → 守护文明。

## 2. 核心玩法循环

```
城镇（白天经营/建造） → 地下通道 → 探索关卡（战斗/掉落）
          ↑                                    ↓
     夜晚防御 ← 回城（触发夜晚准备阶段） ← 自动入库
```

- 城镇：居民采集资源、建筑放置与升级、防御准备。
- 探索：玩家动作战斗（近战/弓箭），杀怪获得金币与怪物材料；背包 + 装备系统；收获自动入库。
- 无彻底失败：玩家探索死亡回到城镇；夜晚未守住，建筑损坏、居民可能死亡；最差情况建筑全毁，玩家仍可继续探索重建。

## 3. 时间系统

- **城镇时间**：白天 → 黄昏 → 夜晚 → 白天。影响居民工作、资源生产、怪物袭击。
- **探索时间**：暂停。玩家在探索关卡中没有时间强制限制，避免被时间赶着走。
- **返回城镇**：触发夜晚准备阶段（具体时长与规则待细化）。
- **探索限制**：探索不消耗城镇时间，依靠背包容量上限与关卡内敌人威胁形成约束，防止无限制囤积。

## 4. 城镇与地图

- 手绘固定地图，不做随机生成；城镇地图在 Godot 主场景内直接绘制（TileMap / 手绘节点）。
- 城镇包含：建筑区域、居民活动、防御区域、地下通道入口。
- 地下通道：进入探索关卡的唯一入口。

## 5. 建筑系统（Demo）

- **放置方式**：玩家选择建筑 → 显示占地范围 → 在城镇地面选定位置 → 校验可建（空格、无碰撞）→ 放置。
- **数据**：`BuildingData` = 名称 / 图标 / 模型 / 占地大小 / 建造材料 / 升级等级 / 功能类型。
- **升级**：所有建筑预留升级接口（等级、造价、效果），Demo 阶段先做结构，不做完整升级链。
- **Demo 建筑**：
  - 篝火（核心建筑）：玩家出生点、城镇中心、解锁建筑。
  - 仓库：扩容库存容量，居民搬运目标；开局库存很少，必须建仓库扩大容量。
  - 伐木屋（职业转换建筑）：提供伐木工名额，把空闲居民转职为伐木工；本身不产资源。
  - 伐木场（资源生成建筑）：在周围生成固定数量的城内树，供伐木工砍伐。
- **预留建筑**：住宅、农场、铁匠铺、训练场、城墙、箭塔。

## 6. 居民系统（Demo）

- **目标**：简单 AI，可扩展。
- **职业分配**：按当前建筑自动分配——例如建造伐木屋后，空闲居民自动前往并成为伐木工执行工作。
- **手动调整**：每日可手动调整一次职业分配，避免"白天伐木、夜晚当兵"的反复切换。
- **数据**：ID / 姓名 / 职业 / 状态 / 工作建筑 / 位置。
- **Demo 职业**：伐木工（找树 → 砍伐 → 捡掉落物 → 运回仓库 → 入库 → 循环）。
- **预留职业**：农民、矿工、工匠、士兵、商人。

## 7. 玩家系统

- **移动**：左右移动（A/D/方向键）、跳跃（空格/W/↑）。
- **战斗**（Demo 已实现）：
  - 近战攻击（J/鼠标左键）：进入攻击状态，命中框在攻击期间启用，带冷却。
  - 弓箭（K/鼠标右键）：生成箭矢投射物，向朝向方向飞行，命中或超时消失，带冷却。
  - 运动与武器参数集中在 `scripts/player/player.gd` 顶部 `@export`，后续迁移到 `resources/data/`。
- **动画**：从素材包 `Free Character Animations` 的 16x16 序列图构建（idle/run/jump/attack/damaged/death），由 `scripts/player/player_animations.gd` 统一管理。
- **背包与装备**：杀怪获得金币与怪物材料，自动入库；装备系统预留。
- **死亡**：探索中死亡 → 回到城镇，无彻底失败。
- **待细化**：攻击伤害数值与命中结算（随敌人系统一起实现）。

## 8. 敌人与夜晚防御

- 夜晚怪物袭击城镇，目标是破坏建筑（优先篝火/城镇中心）。
- 未守住 → 建筑损坏、居民可能死亡；建筑可重建，最差情况全部损坏仍可继续。
- 探索关卡内敌人掉落金币与怪物材料。
- **预留**：更多怪物类型、Boss、怪物巢穴、特殊事件。

## 9. 资源系统

- **开局库存**：木材 10、石头 5，容量上限 20（篝火临时堆点）；建仓库后大幅扩容。
- **木材来源**：
  - 伐木场在城内生成固定数量的树（自给自足）；
  - 城外空地由野外生成器按限量随机生成野生树。
- **采集方式**：居民（伐木工）自动砍树 → 捡掉落物 → 运回仓库 → 入库；玩家不手动采集。
- **树的重生**：按游戏天数（`respawn_days`，默认树 2 天、石头 3 天），由 DayManager 推进。
- **资源节点无碰撞**：树/石头/掉落物只挂 Area2D，玩家与居民可自由穿过。
- **预留资源**：石头、铁矿、食物、特殊材料。
- 资源数值统一进 `resources/data/` 配置（`tree.tres` / `rock.tres`）。

## 9.1 资源经济系统实现记录（2026-08-08）

- `DayManager`（Autoload）：游戏天数，F7 调试推进一天；树重生与野外补树都监听 `day_changed`。
- `EconomyManager`（Autoload）：全局库存/容量/出入库；`deposit` 受容量限制，`withdraw` 供建造扣费。
- `ResourceNode`（Area2D）：预留机制防两人砍同一棵树；耗尽后生成 Pickup 并按 `respawn_days` 重生。
- `Pickup`（Area2D）：地上的掉落物，居民捡起后计入背包并运回仓库。
- `Villager`：通用工作流 IDLE → FIND_WORK → TRAVEL_TO_WORK → WORKING → PICKUP → DEPOSIT；搬运目标优先仓库，其次临时堆点。
- 职业采用**策略模式**：`scripts/villager/jobs/` 下一个职业一个类（实现 find_target / work），新增职业不改通用流程。
- `Villager` 无职业居民：在家附近随机漫游（漫游半径/休息时长可在 Inspector 配置），伐木屋有空位时自动转职。
- 经济开局数据（库存/容量）在 `resources/data/game_config.tres` 中配置。
- 建筑：`StorageBuilding`（扩容）、`WoodcutterHut`（转职伐木工，名额 2）、`LumberCamp`（生成 6 棵城内树）。
- `WildTreeSpawner`：在配置区域内按 `max_trees` 限量随机生成野生树，每天检查补足。

## 11. 技术架构（Godot 4.7.1）

### 目录结构

```
├── docs/           # 设计文档与开发日志
├── assets/         # 原始素材（art/audio/fonts）
├── scenes/         # 场景：main / town / dungeon / player / villagers / enemies / buildings / ui
├── scripts/        # 脚本：autoload / main / town / player / combat / enemy / economy / building / villager / daynight / ui / utils
├── resources/      # 配置数据（data/）与材质资源（shaders/）
└── shaders/        # 着色器源码
```

### 全局单例（Autoload）

| 单例 | 职责 |
| --- | --- |
| EventBus | 全局事件信号，系统间解耦通信 |
| GameManager | 场景切换、暂停、全局状态 |
| SaveManager | 存档/读档（预留） |
| AudioManager | BGM / 音效统一入口（预留） |

### 2D 物理层约定

- 层 1：世界（地面/墙壁等物理阻挡）
- 层 2：玩家
- 层 3：居民
- 资源/掉落物/攻击框等交互体使用 Area2D，不参与阻挡

### 设计原则

1. 系统数据化：建筑、居民、怪物、武器不写死，使用配置数据。
2. 玩法优先：先实现可持续游玩的核心循环，再扩展内容。
3. 保留扩展接口：所有系统预留等级 / 类型 / 属性 / 状态扩展位，避免后期重构。

## 12. Demo 开发优先级

1. **第一阶段**：玩家移动、战斗（近战/弓箭）、探索关卡、返回城镇。
2. **第二阶段**：建筑放置、篝火、伐木屋、木材资源。
3. **第三阶段**：招募居民、居民 AI、职业自动分配、自动生产。
4. **第四阶段**：昼夜循环、夜晚怪物生成、基础防御战斗。
