# 《最后的篝火》城市内 UI 设计文档

> 版本：v0.2（2026-08-08，已实现）
> 状态：已按实施计划完成 v1/v2/v3 全部内容并通过全量测试；随开发迭代更新。

## 1. 目标与设计原则

**目标**：让玩家以“管理者”身份完成完整闭环——查看资源 → 建造/升级 → 分配居民 → 应对夜晚。

**设计原则**：

1. **少遮挡**：横版画面有限，常驻信息只占屏幕顶部一条，其余信息即时弹出、用完即关。
2. **数据驱动**：名称、造价、效果等全部来自建筑/资源配置（`.tres`），UI 只负责显示与调用，不写死数值。
3. **事件驱动**：库存、天数、居民状态变化通过信号刷新对应控件，不做每帧全量刷新。
4. **可替换美术**：占位阶段用色块 + 文字，图标与皮肤统一走主题资源，美术素材到位后直接替换。

## 2. UI 层级架构（CanvasLayer 分层）

| 层 | 内容 |
| --- | --- |
| 常驻 HUD 层 | 顶部状态栏、玩家血条 |
| 面板层 | 建造菜单、建筑详情、居民面板、背包占位面板 |
| 弹窗层 | 确认框（拆除/退出等）、暂停菜单 |
| 通知层 | 左上角事件提示队列（toast） |

层序自下而上：HUD → 面板 → 弹窗 → 通知。通知层永远最上层，保证事件提示不被面板遮挡。

## 3. 模块详案

### 3.1 顶部状态栏（常驻）

半透明底，横跨屏幕顶部，分三区：

- **左侧**：玩家血条（现有血条移入统一布局，条 + 数字）+ 背包按钮（占位入口）。
- **中间**：天数 + 昼夜阶段（☀白天 / 🌇黄昏 / 🌙夜晚）+ 阶段倒计时。
- **右侧**：资源栏（木头、石头、金币、怪物材料，格式 `木材 12/20`）+ 居民栏（`居民 6 · 受伤 1`，点击打开居民面板）。

资源接近容量上限时数字变红；容量由 `EconomyManager.capacity` 驱动。

### 3.2 建造系统

- **打开方式**：按 B 或点击顶栏“建造”按钮，屏幕底部弹出建造条。
- **建造条**：横向卡片列表，每张卡片显示图标（占位色块 + 首字）、名称、造价；资源不足时置灰并标红所缺资源。
- **放置模式**：选中卡片后进入放置状态，鼠标跟随半透明建筑预览——绿色可建、红色不可建；左键确认扣费生成，右键/Esc 取消。
- **放置校验**：不与其他建筑重叠、位置在城镇可建区域内、地面高度合法。校验通过才允许确认。
- **扣费**：确认时调用 `EconomyManager.withdraw()`，扣费失败则不生成建筑并给出提示。

### 3.3 建筑详情面板

点击已建建筑弹出，内容：

- 基本信息：名称、等级、HP。
- 功能信息：建筑功能描述、职业名额（如伐木工 2/2）、已分配居民名单。
- 操作按钮：
  - **升级**：显示下一级造价与效果（数据预留），Demo 阶段可先做 1 级升级或“敬请期待”占位。
  - **修复**：仅建筑损坏时可用。
  - **拆除**：需确认弹窗。

### 3.4 居民管理

- **打开方式**：点击顶栏居民数或按 Tab。
- **面板列表**：每行一个居民——头像（占位）、名字、职业（伐木工/空闲）、状态（工作中/搬运中/漫游/受伤·剩余 X 天）、工作建筑。
- **手动调整职业**：点击居民 → 弹出可转职建筑列表（显示名额剩余）→ 确认转职。
- **每日限制**：每人每天限 1 次手动调整，调整过的置灰并提示“今日已调整”；`DayManager` 推进一天后重置。
- **自动转职**：建好伐木屋后空闲居民自动转职（沿用现有逻辑），通过通知队列提示“阿强成为伐木工”。

### 3.5 玩家状态

- 血条保留并统一样式（条 + 数字）。
- 背包/装备本次只做入口占位：点开显示“背包系统随地下城开放”，不实现空壳功能。

### 3.6 昼夜与夜晚预警

- 阶段图标 + 倒计时常驻顶栏（见 3.1）。
- 进入黄昏：屏幕边缘轻微压暗 + 横幅“夜晚将至，怪物即将来袭”。
- 夜晚波次：横幅“第 3 波敌人来袭”。
- 天亮结算：横幅“夜晚过去，损坏建筑 X 处”。

### 3.7 交互提示

靠近地下通道等可交互物时，屏幕下方显示“按 E 进入地下通道”等提示，统一交互键 E。

### 3.8 通知队列（toast）

- 位置：左上角，最多同时 3~4 条，自动消失，可配置开关。
- 内容示例：资源入库（木材 +3）、建筑建成/损坏、居民受伤（阿强受伤了，2 天后恢复）、夜晚来袭。

### 3.9 暂停菜单

按 Esc 暂停游戏（`get_tree().paused`），弹出：继续 / 设置（音量、画面，占位）/ 存档（预留）/ 返回标题。暂停时鼠标可见。

## 4. 键位方案

| 功能 | 按键 |
| --- | --- |
| 移动 / 跳跃 | WASD / 方向键，空格 |
| 近战 / 弓箭 | J / K（保留现有） |
| 交互 | E |
| 建造菜单 | B |
| 居民面板 | Tab |
| 背包 | I（占位） |
| 暂停 | Esc |

新增键位统一注册为 InputMap 动作（`interact` / `build_menu` / `villager_panel` / `pause`），由各 UI 脚本监听，不与现有移动/攻击动作冲突。

## 5. 架构补充：TownRegistry（城镇登记表）

居民与建筑的状态目前散在场景节点中，UI 直接查组会绕且难以测试。新增轻量 Autoload `TownRegistry` 作为 UI 的唯一查询入口，也为后续存档打基础。

**职责**：

- 登记/注销居民（villagers）与职业建筑（job_huts）。
- 查询：全部居民、某建筑名额、某居民状态与工作建筑。
- 记录每日手动调整次数，监听 `DayManager.day_changed` 在每日推进时重置。

**接口草案**：

```gdscript
signal villager_registered(villager)
signal adjustment_reset()

func register_villager(v) -> void
func unregister_villager(v) -> void
func get_villagers() -> Array
func register_job_hut(hut) -> void
func get_job_huts() -> Array
func adjusted_today(villager_id: int) -> bool
func mark_adjusted(villager_id: int) -> void
func reset_daily_adjustments() -> void
```

**依赖**：`DayManager`（重置次数）、`EventBus`（可选的通知转发）。

## 6. 数据流

- HUD 订阅信号：`EconomyManager.stock_changed`（资源栏）、`DayManager.day_changed / phase_changed`（天数与阶段）、玩家 hp（现有血条逻辑）、`EventBus` 事件（建筑建成/损坏、居民受伤/转职、夜晚波次）。
- 建筑卡片数据：读建筑配置 `.tres`（名称/造价/描述），UI 只读。
- 放置流程：选卡片 → 预览（校验）→ 确认 → `EconomyManager.withdraw()` → 生成建筑场景。
- 转职流程：居民面板点击 → 校验名额与每日次数 → 调 `set_job()`。

## 7. 错误处理

| 场景 | 处理 |
| --- | --- |
| 资源不足 | 建造卡片置灰 + 标红所缺资源 |
| 放置位置非法 | 红色预览，不响应确认 |
| 职业名额已满 | 转职按钮禁用 |
| 今日已调整 | 居民行置灰，提示“今日已调整” |
| 扣费失败 | 不生成建筑，toast 提示资源不足 |

## 8. 测试策略

- **逻辑单测**：放置校验（重叠/区域/高度）、建造扣费、每日调整次数上限、容量显示。
- **UI 冒烟**：hud.tscn 可加载、面板开合、建造流程端到端（选卡片 → 放置 → 扣费 → 生成）。
- 沿用现有 `tests/run_all.gd` 框架，`godot --headless` 可跑。

## 11. 实现记录（2026-08-08）

- 新增 Autoload `TownRegistry`：居民/职业建筑登记表 + 每日调整次数（按天重置）。
- 顶部状态栏：血条、天数、昼夜阶段与倒计时、木材/石头/金币/材料、库存容量、居民数与受伤数、建造/居民/背包入口。
- 建造菜单：底部卡片列表（读 `resources/data/buildings/*.tres`），资源不足置灰。
- 放置控制器：半透明预览（绿=可建/红=不可建）、区域/落地/间距校验、左键确认扣费生成、右键/Esc 取消；放置期间屏蔽玩家输入。
- 建筑详情：名称/等级/HP/职业名额/已分配居民；修复/重建/拆除（确认弹窗）；升级按钮占位。
- 居民面板：列表（姓名/职业/状态/受伤剩余天数）+ 转职选项（职业建筑名额/转空闲），每人每天限一次，次日重置。
- 交互提示：靠近地下通道等 `interactables` 显示"按 E"，按 E 触发。
- 夜晚预警：黄昏/夜晚压暗 + 横幅；白天显示夜晚结算（损坏建筑数）。
- 通知队列：左上角 toast（建筑建成/摧毁、居民受伤/转职、夜晚波次、玩家拾取）。
- 暂停菜单：继续/设置（占位）/存档（预留）/返回标题。
- 背包占位面板：金币/材料数量，装备系统随地下城开放。
- 键位：B 建造菜单、Tab 居民面板、E 交互、I 背包、Esc 暂停（均注册进 InputMap，避开 F5-F8）。
