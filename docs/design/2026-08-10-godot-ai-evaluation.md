# godot-ai 插件评估（v0.1）

> 状态：已评估，暂不安装；触发条件满足后再装（见第 6 节）。
> 仓库：https://github.com/hi-godot/godot-ai
> 评估日期：2026-08-10

## 1. 定位

**godot-ai 是 Godot 编辑器 AI 开发辅助插件**，不是游戏内 NPC AI。

它通过 MCP（Model Context Protocol）把正在运行的 Godot 编辑器桥接给 AI
客户端（Claude Code、Codex、Cursor 等），让 AI 能直接操作编辑器：
建节点、改属性、写脚本、跑游戏、读日志、截图、模拟输入等。

**它不能**替我们解决游戏设计问题：居民 AI、战斗逻辑、怪物行为这些仍然
需要我们自己写代码实现。

## 2. 安装要求

| 项目 | 要求 | 本机状态 |
| --- | --- | --- |
| Godot | 4.5+（4.7+ 推荐） | 4.7.1 满足 |
| uv（Python 包管理器） | 必需 | 未安装（用时再装） |
| Godot 编辑器 | 需保持打开并启用插件 | — |

安装方式推荐：GitHub 源码版（`addons/godot_ai` 拷入项目 `addons/`），
比 Godot 资源库版本更新更快。

## 3. 核心能力（约 43 个 MCP 工具）

与本项目开发直接相关的能力：

- **场景操作**：建节点、改属性、移动/重命名/删除/复制节点、打开保存场景
- **脚本操作**：创建/修改 GDScript，写入时直接返回语法诊断（边写边编译检查）
- **运行与调试**：启动游戏、读游戏/编辑器日志（报错定位到脚本行）、编辑器/游戏截图
- **UI 搭建**：锚点、布局、主题、StyleBox、批量绘制 UI（draw_recipe）
- **测试**：在编辑器内跑 GDScript 测试套件并取结果
- **模拟输入**：键盘/鼠标/手柄模拟，支持按帧精确执行操作序列（自动化验收）
- **资源类**：TileMap/TileSet、动画、粒子、材质、音频、相机、信号、输入映射

## 4. 对项目的价值评估

### 当前工作流（无需插件）

- 直接修改 .gd/.tscn 文件 + 命令行无头跑测试（49 个测试全绿）
- 画面验证依赖用户手动截图反馈

### 安装插件后新增的价值

1. **可视化闭环**：可自行启动游戏并截运行画面，减少"我看不到画面"的沟通成本
2. **场景编辑提速**：做地下城、怪物场景、TileMap 时可直接在编辑器里操作，
   不必手写 .tscn 猜坐标
3. **游戏内自动化验收**：模拟按键/鼠标跑"攻击→受伤→死亡"流程，贴近真实手感
4. **日志闭环**：运行时报错可直接读到带定位的错误日志

### 代价

- 需安装 uv + Python 依赖（一次性环境配置）
- 要求 Godot 编辑器保持打开并启用插件
- 多一层运行时依赖，出问题时要排插件本身

## 5. 结论

**暂不安装。** 当前处于城市内玩法收尾 + 存档收尾阶段，插件带来的增量
用不上；现有"改文件 + 无头测试"节奏稳定可靠。

## 6. 触发安装的条件

满足以下任一条件时按第 7 节安装：

- 开始制作**地下城场景**（大量节点/关卡搭建）
- 开始**战斗手感调试**（需要反复看画面、试手感）
- 需要**游戏内自动化验收**（如怪物波次、战斗流程回归）

## 7. 安装备忘（用时执行）

```bash
# 1. 安装 uv（Windows PowerShell）
irm https://astral.sh/uv/install.ps1 | iex

# 2. 获取插件源码
git clone https://github.com/hi-godot/godot-ai.git
# 将 godot-ai/plugin/addons/godot_ai 拷入项目 addons/ 目录

# 3. Godot 编辑器内启用
# Project > Project Settings > Plugins，启用 Godot AI

# 4. 配置 Codex 客户端（~/.codex/config.toml）
[mcp_servers."godot-ai"]
command = "godot-ai"
args = ["attach", "--port", "8000", "--ws-port", "9500"]
enabled = true
startup_timeout_sec = 60
tool_timeout_sec = 360
```

配置细节以仓库 README 为准（插件版本更新可能改变命令形状）。
